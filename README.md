# Оқу топтарын есепке алу

Бұл жоба университеттегі оқу топтарын есепке алуға арналған қарапайым Python қосымшасы.

## Мүмкіндіктері
- Жаңа оқу тобын қосу
- Оқу топтарының тізімін көрсету
- Топтағы студенттер санын сақтау
- Топты атауы бойынша іздеу

## Қолданылған құралдар
- Python
- Git
- GitHub
- GitHub Actions
- unittest

## Тестілеу
Жобада екі unit-тест бар:
1. Оқу тобын қосу функциясын тексеру
2. Оқу тобын іздеу функциясын тексеру

## CI/CD
GitHub Actions көмегімен Build → Test процесі автоматты түрде орындалады.
